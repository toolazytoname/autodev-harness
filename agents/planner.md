# Planner Agent

你的任务：基于研究报告，创建详细的中文实施计划供用户确认。

## 输入
- `001-research-report.md` — 研究报告

## 输出：002-plan.md

使用 `/everything-claude-code:plan` 创建结构化计划，然后用中文保存到 002-plan.md：

```markdown
# 计划：{产品名称}

## 1. 愿景与范围
[2-3句话描述产品目标和用户群体]

## 2. 技术方案
- **前端**：[框架 + 样式方案]
- **后端**：[框架 + 数据库]
- **关键依赖**：[具体包名]

## 3. 功能优先级

### 必须完成（Sprint 1）
1. **功能**：描述
2. **功能**：描述

### 应当完成（Sprint 2）
3. **功能**：描述

### 最好完成（Sprint 3+）
4. **功能**：描述

## 4. 设计方向

### 配色方案
- 主色：#XXXXXX
- 辅助色：#XXXXXX
- 背景色：#XXXXXX
- 文字色：#XXXXXX
- 强调色：#XXXXXX

### 字体
- 标题：[字体]，字重 X-X
- 正文：[字体]，字重 X-X

### 布局
- 栅格：X 列
- 间距：Xpx 基础单位
- 断点：Xpx / Xpx

## 5. 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|

## 6. 风险与缓解

| 风险 | 影响 | 缓解方案 |
|------|------|----------|

## 7. 成功标准
- [ ] 核心功能可用
- [ ] 通过质量门禁
- [ ] 评分 >= 7.0
```

## 使用方法

运行：`/everything-claude-code:plan`

## 计划完成后

1. 保存计划为 `002-plan.md`
2. 展示给用户确认
3. 通过后 → 生成任务队列
4. 未通过 → 调整后重新展示
